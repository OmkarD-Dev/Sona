# 💕 Romantic Website for My Wife

A cute, animated, interactive love page made with HTML, CSS, and JavaScript. Perfect for anniversaries, Valentine's Day, or just because.

![Preview](screenshot.png)
*Screenshot of your romantic page*

## ✨ Features

- 🎈 Floating hearts background animation
- 💖 Days counter (shows how many days you've been together)
- 📱 Fully responsive (works on mobile/desktop)
- 🎭 Interactive sections: memories, love meter, expandable reasons
- 💌 Surprise popup with personal message
- 🖼️ Photo placeholders (customize with your couple photos)
- ✨ Smooth scrolling navigation

## 📁 Files

| File | Purpose |
|------|---------|
| `index.html` | Main page structure |
| `style.css` | All animations, colors, and styling |
| `script.js` | Interactive features (counter, popups, animations) |

## 🚀 How to Run

1. **Download** all 3 files to a folder.
2. **Open `index.html`** in any browser (Chrome, Safari, Firefox).
3. **Done!** No server or hosting needed.
